01 / THE COURSE
FROM CODE TO PRODUCT

YOU ALREADY KNOW
HOW TO USE SOFTWARE. NOW LEARN HOW IT GETS BUILT.

THUG NAVI™ started as a visual link dashboard and evolved toward a real local-first desktop workspace.

Building it required more than learning syntax.

We had to design an interface, manage application state, organize links and files, model projects, persist local data, connect the filesystem, bridge the interface to native desktop capabilities and package the product.

THIS COURSE IS ABOUT THAT JOURNEY.

06 / THINK IN SYSTEMS
ONE OF THE BIGGEST LESSONS

THE DASHBOARD IS NOT
THE APPLICATION.

The visible dashboard is only one layer.

Tauri and Rust form the native desktop layer.

SQLite forms the persistence layer.

The filesystem is another boundary.

Packaging and distribution are another layer.

They can work together without becoming the same thing.

LEARNING TO SEE THOSE BOUNDARIES IS LEARNING SOFTWARE ARCHITECTURE.
